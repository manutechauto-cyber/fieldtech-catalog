# FieldTech Engineer Catalog

Official downloadable VFD/drive data-pack catalog for **FieldTech Engineer**.

## Current families

- Siemens: SINAMICS G120, G120C, G120X, S120, V90
- Allen-Bradley: PowerFlex 525, 527, 753, 755
- Danfoss: VLT Midi Drive FC 280, VLT AutomationDrive FC 302
- WEG: CFW500, CFW700, CFW900
- SEW-EURODRIVE: MOVIFIT, MOVIDRIVE
- ABB: ACS355, ACS580, ACS880
- Schneider Electric: ATV320, ATV630, ATV930

The FieldTech Engineer app reads `manifest.json`, downloads individual JSON packs, and stores them locally for offline use. Packs marked as starter metadata are placeholders for families that are already recognized while detailed parameter and fault data is progressively curated.

FieldTech Engineer is a field-reference tool and does not replace current manufacturer documentation for safety-critical commissioning, parameterization, or troubleshooting.
